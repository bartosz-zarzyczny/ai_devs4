# L12 - firmware

## Task

Run the firmware binary on a restricted Linux virtual machine, obtain the secret code it prints,
and submit it to the hub.

- **Binary**: `/opt/firmware/cooler/cooler.bin`
- **Code format**: `ECCS-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
- **Task name**: `firmware`
- **Shell API**: `POST https://hub.ag3nts.org/api/shell`  `{"apikey":"...", "cmd":"help"}`
- **Verify**: `POST https://hub.ag3nts.org/verify`  `{"apikey":"...", "task":"firmware", "answer":{"confirmation":"ECCS-..."}}`

## Approach

An agentic loop driven by `anthropic/claude-sonnet-4-5` is given two tools:

| Tool | Purpose |
|------|---------|
| `shell_cmd` | Execute one command on the remote VM via the shell API |
| `submit_answer` | Send the found ECCS code to `/verify` |

### What the agent does

1. Reads `.gitignore` in `/opt/firmware/cooler/` and respects all listed paths.
2. Reads `/home/operator/notes/pass.txt` (and `bash_history` for hints) to find the password (`admin1`).
3. Edits `settings.ini` with `editline`:
   - Uncomments `SAFETY_CHECK` and sets the real password.
   - Sets `[test_mode] enabled=false`.
   - Sets `[cooling] enabled=true`.
4. Removes `cooler-is-blocked.lock` if needed.
5. Runs `/opt/firmware/cooler/cooler.bin admin1` and captures the `ECCS-...` code.
6. Submits the code to `/verify` and saves the result.

### Security rules respected

- Never accesses `/etc`, `/root`, or `/proc/`.
- Respects `.gitignore` (`.env`, `storage.cfg`, `logs/` are off-limits).
- Rate-limit guard: minimum 3 s between shell API calls.

### Result

Main task flag: **`{FLG:XXXXXXXXXXX}`** (returned by `/verify` after submitting the ECCS code).

## Bonus — flaggengenerator

### Riddle

> **"Uruchom mnie z niemieckim motylem"**
> ("Run me with a German butterfly")

`motyl` (Polish) = butterfly. German: **Schmetterling** (`schmetterling` lowercase).

### Solution

```bash
/bin/flaggengenerator schmetterling
```

Returns base64-encoded output: `e0ZMRzpCUkFUV1VSU1R9`

Decoded: **`{FLG:XXXXXXXXXX}`**

### Reproducing manually

```python
import base64
base64.b64decode('e0ZMRzpCUkFUV1VSU1R9').decode()  # '{FLG:XXXXXXXXXXXX}'
```

Or via the UI — click the **"Run flaggengenerator"** button in the flag bar.

## Setup

```
pip install -r requirements.txt   # from repo root
```

`.env` at repo root must contain:

```
AI_DEVS_4_API_KEY=...
API_OPEN_ROUTER_KEY=...
```

## Running

### Agentic solver

```
python L12/task.py
```

Pass `--reboot` to reset the VM to its initial state before starting:

```
python L12/task.py --reboot
```

### Browser UI

```
python L12/ui_server.py
```

Open **http://localhost:8080** — the UI shows:

- **Flag card** with the obtained `{FLG:...}` value and the `ECCS-...` code.
- **Agent steps log** — collapsible list of every shell command run by the agent and its output.
- **Manual terminal** — type any allowed command (`ls`, `cat`, `editline`, etc.) directly against the VM.  Commands are rate-limited to 1 per 3 s to avoid bans.
- **Reboot VM** button — resets the virtual filesystem to its initial state.
